3) EVOLUTION FONCTIONNELLE REALISEE
====================================================================
A. Monitoring Drift ajoute dans le code applicatif
--------------------------------------------------
Fichier ajoute:
- madewithml/drift_monitor.py

Fonctions et logique ajoutees:
1. Calcul PSI (Population Stability Index)
   - PSI longueur texte en caracteres.
   - PSI longueur texte en tokens.
2. Calcul KL divergence
   - KL distribution langues.
   - KL distribution vocabulaire top-k.
3. OOV rate (Out-Of-Vocabulary rate)
   - Proportion de tokens hors vocabulaire baseline.
4. Fenetre glissante online
   - Suivi des N dernieres predictions (window_size configurable).
5. Publication Prometheus (Gauge)
   - Exposition automatique des metriques pour /metrics.

Metriques exposees:
- madewithml_drift_window_samples
- madewithml_drift_text_length_chars_psi
- madewithml_drift_text_length_tokens_psi
- madewithml_drift_language_kl
- madewithml_drift_vocab_kl
- madewithml_drift_oov_rate

B. Integration dans l API FastAPI
---------------------------------
Fichier modifie:
- madewithml/serve.py

Ajouts principaux:
1. Initialisation conditionnelle du DriftMonitor au demarrage app.
2. Mise a jour des metriques drift a chaque appel POST /predict/.
3. Variables d environnement supportees:
   - DRIFT_MONITOR_ENABLED (default true)
   - DRIFT_BASELINE_DATASET (default datasets/dataset.csv)
   - DRIFT_WINDOW_SIZE (default 500)
   - DRIFT_VOCAB_TOP_K (default 200)
4. Validation robuste des env vars entieres (fallback si valeur invalide).
